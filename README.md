# Cherry Money — Monad Metropolis

Hackathon repository for **Cherry Pay Global** on Monad.

This repository is intentionally isolated from the production Cherry Money codebase. It will contain the complete Metropolis implementation:

- React Native mobile app
- Mera passkey account layer
- Agora AUSD payments on Monad
- Chainlink CRE workflow
- Envio indexing and settlement analytics
- smart contracts
- integration adapters for Cherry Money
- demo, security and bounty documentation

## Development

Feature work is developed on branches and merged into `main` through pull requests.

The first delivery branch is `feat/phase-1-foundation`.
